About SimpleZTA

        

          
          

            
Built on the Microsoft Zero Trust Assessment. The controls, their metadata, the remediation guidance and the official report template come from the ZeroTrustAssessment PowerShell module, copyright Microsoft Corporation, MIT licence. The module is bundled in the powershell folder of this tool.

            
SimpleZTA is an independent browser port. It is not made or supported by Microsoft; where results differ, the PowerShell module is the reference.

          

        

        


        
What it does

        
    
          
  • Runs every control of the module as a browser check with delegated Graph (and, when you include Azure controls, Azure Resource Manager) calls.
    • 
          
  • Controls that need an admin PowerShell session (Purview, Exchange Online, SharePoint Online) come back as Skipped with the reason.
    • 
          
  • Dashboard with pillar scores, sankeys for CA/MFA coverage, auth methods and device compliance, a pillar by risk heatmap and the top fixes.
    • 
          
  • Exports the official Microsoft report, a standalone SimpleZTA report, a Zero Trust Workshop import file, Excel, CSV and JSON.
    • 
          
  • Keeps earlier scans so you can see trends and what regressed or got fixed between two runs.
    • 
        


        
What is stored in this browser

        
Scan history lives in localStorage of this browser, for this site, with no expiry. Anyone using this browser profile can see it. Nothing goes to a server.

        
    
          
  • Scans: per control the status, summary, evidence (user names, role members, policy names and the like) and the API calls made, with each response cut to its first 1000 characters. Plus the tenant insight aggregates behind the dashboard graphics.
    • 
          
  • Scan profiles you saved and the last control selection.
    • 
          
  • Tokens are not stored with the scans; sign-in lives in this tab only.
    • 
        

        
Remove it with History, Clear history. Export a scan first if you need it later.
