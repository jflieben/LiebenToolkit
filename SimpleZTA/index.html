About

        
SimpleZTA is a browser-native implementation by Lieben Consultancy, inspired by and mapped to the Microsoft ZeroTrustAssessment PowerShell module.

        
Copyright and credit: Microsoft ZeroTrustAssessment module is copyright Microsoft Corporation. This tool provides a client-side companion UX for delegated Graph-based assessment workflows.

        
SimpleZTA stores scan history only in your local browser storage, export it before you clear your browser if you have later need of it.
