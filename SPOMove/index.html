    What kind of transfer is this?

    Choose whether you are moving files inside one Microsoft 365 tenant or between two different tenants.

    Connect the source tenant

    Sign in to the tenant that currently holds the files. SPOMove runs entirely in your browser using OAuth2 PKCE (public Lieben Consulting app). Your tokens and file data never leave your browser.

    Pick the source location

    Search for a site or paste its URL, choose a document library, then optionally drill into a subfolder. Everything under the selected folder is transferred.

    Connect the target tenant

    Sign in to the destination tenant. This opens a second sign-in popup so both connections stay active at the same time.

    Pick the target location

    Choose where the files should land. Folders that do not exist yet are created automatically.

    About SPOMove
    
        
    SPOMove is a fully client-side single-page app for moving and copying SharePoint Online files between sites - in the same tenant or across two tenants. No backend, no telemetry, no data leaves your browser. It signs you in with Microsoft (OAuth2 PKCE) using the public Lieben Consulting multi-tenant app and calls the Microsoft Graph and SharePoint REST APIs directly as you.
    

        
    How transfers run
    
        
      
          
    • Same tenant: uses SharePoint's server-side SP.MoveCopyUtil so file bytes never travel through your browser - fast and efficient even for large libraries.
      • 
          
    • Between tenants: downloads each file from the source and uploads it to the target (chunked upload for large files). Because the data passes through your browser, very large libraries are slower and bound by your connection and memory.
      • 
          
    • Previous versions: when enabled, each historical version is replayed in order onto the target (best-effort; streams through the browser).
      • 
          
    • Metadata: Author, Editor, Created and Modified are preserved where the principals can be resolved in the target web.
      • 
        
    

        
    Finding source & target locations
    
        
      
          
    • Sites: search by name for sites you can access, or paste a site URL.
      • 
          
    • OneDrive (by user): type a person's name or UPN to open their OneDrive directly.
      • 
          
    • All sites (admin): SharePoint Administrators can list every site collection in the tenant - including ones they have no access to yet - and use Take ownership to elevate.
      • 
        
    

        
    Reports
    
        
    When a job finishes, a report opens with a success/failure chart, totals, duration and a searchable, filterable list of every file - so you can drill straight into failures and their error messages, or export the full list as CSV.
    

        
    Resumable jobs
    
        
    Every job and its per-file progress are kept in your browser's local storage. If a run is interrupted you can resume it from the Jobs tab and only the remaining files are processed.
    

        
    Taking ownership
    
        
    If you cannot read a site you need, and you hold the SharePoint Administrator role, SPOMove can temporarily add you as a site collection administrator so the transfer can proceed.
    

        
    Required delegated permissions
    
        
      
          
    • User.Read - sign-in identity and tenant detection
      • 
          
    • User.ReadBasic.All - look up a user's OneDrive (only requested when you use the OneDrive-by-user picker)
      • 
          
    • AllSites.FullControl / Sites.FullControl.All (SharePoint) - read source files, write target files, set metadata, list all sites and take ownership
      • 
        
    
        
    The first sign-in may trigger an admin-consent prompt if your tenant has not consented to the app yet.
