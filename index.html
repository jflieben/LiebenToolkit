LC Toolkit

Browser-based tools for Microsoft Cloud admins

Small, focused tools that just run in your browser.

No backend, no telemetry. You use your own account, your browser talks to Microsoft directly.

In this repo

Import, export and compare Conditional Access policies. Add name prefixes/suffixes, set policy mode per import item, resolve missing users/groups, and bootstrap with a starter baseline set.
